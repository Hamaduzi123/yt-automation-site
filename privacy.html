Privacy Policy

Last updated: 30 October 2026

YT Automation ("the app") is a private tool operated by the owner of the ASHOKA MEDIA TV YouTube channel for managing that channel only.

Data accessed

With the owner's authorization through Google OAuth, the app uses the YouTube Data API and YouTube Analytics API to upload and edit videos, thumbnails, captions and playlists on the owner's channel, and to read that channel's analytics.

Storage and sharing

OAuth tokens and analytics are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. The app does not collect data from other YouTube users.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
